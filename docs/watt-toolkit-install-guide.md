# Watt Toolkit 安装指引（原 Steam++）

> 适用场景：通过本技能安装 Watt Toolkit（网络加速/游戏工具箱）时，因其官方 Windows 安装器**不支持命令行静默安装**，技能会负责下载、校验并启动安装器，最后由你在弹出的图形向导里手动完成安装。
> 面向新手，按步骤说明每个选项该怎么选。

## 软件简介

**Watt Toolkit**（原名 **Steam++**）是一款开源跨平台的网络加速与游戏工具箱，常用来加速访问 GitHub、Discord、Steam、Google 等服务，以及 Steam 账号管理、多账号切换等。
**注意**：**加速功能无需登录账号即可使用**（经实测）；仅部分高级功能（如账号管理、库存查看等）才需要登录账号。

---

## 安装前的准备

1. 技能会先自动下载最新**稳定正式版 3.1.0** 的安装包（`Steam++_v3.1.0_win_x64.exe`）并校验文件完整性。
2. 安装到 `Steam++` 目录（默认 `C:\Program Files\Steam++`），**需要管理员权限**。启动时会弹出 UAC 提权窗口，请点 **"是"**。

---

## 安装向导步骤（共 3 步）

技能启动安装器后，会弹出图形安装向导。按下面操作：

### 第 1 步：选择安装路径
- 界面让你选择安装目录。
- **小白直接保持默认**（`C:\Program Files\Steam++`），或点击"自定义安装"改到非系统盘（如 D 盘）以防 C 盘空间不足。
- 点 **"下一步 / Next"** 或继续。

### 第 2 步：立即安装
- 点击 **"立即安装 / Install"** 按钮。
- 等待进度条到 **100%**。
- 安装完成后，按钮会变成 **"立即体验 / Start"**。

### 第 3 步：立即体验
- 点击 **"立即体验 / Start"**，软件开始运行。
- 至此安装完成。

> 首次启动如需更新，让它在**设置里自动更新**即可；后续新版本通常由软件内置自动更新处理。

---

## 安装完成后

回到技能对话，告诉它"装好了"，技能会检查安装位置的 `Steam++.exe`（如 `D:\Program Files\Steam++\Steam++.exe`）是否存在，确认安装成功。

安装成功后使用前请注意：
1. **加速无需登录**：打开软件即可直接使用加速功能；如需用到需登录的高级功能，再按提示登录（GitHub / Steam 账号均可）。
2. 加速网络功能需以**管理员权限**运行软件（右键图标 →"以管理员身份运行"）才能生效。
3. 部分杀毒软件可能对加速相关组件报提示，请按需放行或加入白名单。

## 常见问题（FAQ）

**Q1：安装向导没有弹出？**
说明技能启动安装器后等待稍慢。请告知技能"重新启动安装器"，或手动双击技能下载好的安装包再次运行。

**Q2：弹出"管理员权限"提示/杀毒拦截？**
点"是"/允许即可，安装到 Program Files 需要管理员权限；Watt Toolkit 是开源可信软件，但加速组件个别情况会被误报，添加到信任即可。

**Q3：装完打不开加速功能？**
多半是没以管理员身份运行。右键软件图标选"以管理员身份运行"即可（加速功能无需登录账号）。

**Q4：为什么不是最新的 rc 版本？**
本技能固定使用**最新稳定正式版 3.1.0**（候选版 rc.16 官方注明数字签名到期、可能被杀毒误报，故不用）。升级需在配置中手动更新 version 与下载地址。
